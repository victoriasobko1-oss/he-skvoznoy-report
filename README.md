# Сквозная отчетность | Магистратура (high-education)

Интерактивный HTML-отчёт (селекторы + таблица канал → период).

## Локально

Открыть `index.html` через любой static server (из‑за `fetch('data.json')`):

```bash
python3 -m http.server 8080
```

## Данные

`data.json` — снимок витрины (сейчас: Метрика, сен–ноя 2026, зерно месяц).

Обновление позже: скрипт выгрузки → перезапись `data.json` → push в репо (GitHub Pages подхватит).

## Селекторы

| Селектор | Сейчас |
|----------|--------|
| Даты от/до | работают (календарь браузера) |
| Канал / тип кампаний | режут витрину |
| Количество недель | режет месяцы по `date_to` |
| Масштаб неделя/день | UI есть, зерно пока только месяц |
| UTM / точка входа | UI есть, ждёт зерно / склейку amo |
| Расход Директа | ждёт одобрения API-заявки |
